# Методология КЭМП-ЛИЛА

## Концепция

Адаптация древней игры Лила (Leela Chakra) под мужское сообщество **КЭМП** — Клуб Эффективного Мужского Прогресса.

Игра — не развлечение. Это **зеркало пути мужчины**: от физического тела до легендарного наследия.

---

## Игровое поле

### Структура
- **72 клетки** (8 колонок × 9 рядов)
- Расположение змейкой (snake pattern): снизу вверх, чётные ряды справа налево
- **6 уровней (планов сознания)**

## Механики

### Бросок кубика
- Стандартный 6-гранный кубик (1–6)
- Ход поочерёдный (в мультиплеере)
- **Отскок**: если перебросил 72 — отскакиваешь назад на разницу
  - Пример: на 70-м бросил 5 → 70 + 5 = 75 → отскок: 72 − (75 − 72) = 69

## Режимы игры

### 1. Соло (против себя)
- Игрок идёт один
- Цель: пройти 72 клетки, выполняя задания
- Прогресс сохраняется в localStorage
- Можно ставить на паузу и возвращаться

### 2. С ИИ (2–4 игрока + боты)
- Боты с 2 уровнями сложности:
  - **Лёгкий**: случайные броски, без стратегии
  - **Сложный**: "притворяется человеком" — иногда ошибается, но знает змеи/стрелы

### 3. Мультиплеер (2–4 друга)
- Комната с кодом приглашения
- Real-time синхронизация ходов (Supabase Realtime)
- Ход поочерёдный
- Чат внутри комнаты (опционально)

## Цикл игровой сессии

1. **Выбор режима** → Соло / Мультиплеер / С ИИ
2. **Создание игры** → Имя игрока, цвет фишки
3. **Игровой экран** → Поле, кубик, статус
4. **Бросок** → Анимация кубика (0.8 сек)
5. **Движение** → Анимация фишки по клеткам
6. **Проверка** → Змея? Стрела? Обычная клетка?
7. **Модалка клетки** → Описание + задание
8. **Следующий ход** или **Победа**

---

## Задания клеток

Каждая клетка содержит **практическое задание** — не абстрактное, а конкретное действие:
- Физическое (50 отжиманий, пробежка)
- Рефлексивное (написать, признать, простить)
- Социальное (позвонить брату, сказать близкому)
- Дисциплинарное (подъём в 5:00, день без сахара)

Игрок может:
- Выполнить задание → отметить "Сделано" → бонус в статистике
- Отложить → задание идёт в "Квесты"
- Пропустить → без штрафа, но без бонуса

- Пройдено клеток за все игры
- Выполнено заданий
- Попаданий на змеи / стрелы

- Среднее время партии

### Уровни игрока
- **Новичок** (0–5 игр)
- **Боец** (6–20 игр)
- **Воин** (21–50 игр)
- **Мастер** (51–100 игр)
- **Легенда** (100+ игр)
