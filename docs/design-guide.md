# Дизайн-гайд КЭМП-ЛИЛА

## Бренд

**КЭМП** — Клуб Эффективного Мужского Прогресса

- **Логотип**: Кулак с красными бинтами + гранж-шрифт
- **Файлы**: `public/logo-white.png`, `public/logo-fist.png`
- **Характер**: Жёсткий, минималистичный, военно-спортивный, без понтов

## Компоненты

### Игровое поле (Board)

- **Размер клетки**: 44×44px (мобильный), 52×52px (планшет)
- **Отступы**: 2px между клетками
- **Радиус скругления**: 6px
- **Цвет клетки**: Цвет уровня с opacity 0.85
- **Змея**: opacity 0.75, красная граница
- **Стрела**: opacity 0.95, зелёная граница
- **Hover**: белая рамка 2px

### Кубик (Dice)

- **Размер**: 80×80px
- **Форма**: Квадрат, radius 12px
- **Состояния**:
  - Обычное: тёмный фон, красная рамка
  - Бросок: пульсирующий жёлтый фон
  - Disabled: серый, opacity 0.5
- **Иконка**: Unicode кости (⚀ ⚁ ⚂ ⚃ ⚄ ⚅)

### Модалка клетки (Cell Modal)

- **Фон**: `#141414` с border `#C41E3A/20`
- **Ширина**: 90vw, max-width 360px
- **Внутренние отступы**: 24px
- **Заголовок**: КЭМП-красный, uppercase
- **Описание**: серый, line-height 1.6
- **Задание**: левая граница красная 2px, тёмный фон
- **Кнопка**: КЭМП-красный фон, чёрный текст

### Фишка игрока

- **Форма**: Круг, 20px диаметр
- **Обводка**: белая, 2px
- **Цвета игроков**: Золотой `#C9A96E`, Зелёный `#4A7C59`, Синий `#2E5AAC`, Красный `#8B2635`
- **Позиционирование**: Центр клетки + offset для мультиплеера

## Экраны

### 1. Экран загрузки / Сплеш

- Фон: `#0A0A0A`
- По центру: Логотип КЭМП (кулак + название)
- Анимация: пульсация кулака
- Длительность: 2 секунды

### 2. Главное меню

- Логотип КЭМП сверху
- Кнопки:
  - 🎮 Начать путь (Соло)
  - 👥 Играть с братьями (Мультиплеер)
  - 🤖 Против ИИ
  - 📊 Моя статистика
  - ⚙️ Настройки

### 3. Игровой экран

- **Верх**: Логотип мини + имя игрока + текущая клетка
- **Центр**: Игровое поле (SVG)
- **Низ**: Кубик + статус + кнопка меню
- **Оверлей**: Модалка клетки (при попадании)

### 4. Экран победы

- Фон: градиент фиолетовый → чёрный
- Текст: "ЛЕГЕНДА" (72-я клетка)
- Статистика партии
- Кнопки: "Новая игра", "Поделиться"

## Принципы дизайна

1. **Минимализм** — нет лишнего. Только поле, кубик, текст.
2. **Контраст** — тёмный фон, яркие клетки, белый текст.
3. **Иерархия** — крупные заголовки, читаемые описания.
4. **Отзывчивость** — каждое действие даёт haptic feedback.
5. **Мужской характер** — нет округлых «милых» элементов. Только чёткие линии.
