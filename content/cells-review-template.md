# Ревью клеток: шаблон для правки

> Открой `content/cells-draft.md` рядом с этим файлом.  
> Для каждой клетки принимаешь одно из решений: ✅ Оставить / ✏️ Править / ❌ Удалить-переделать

---

## Критерии проверки (по каждой клетке)

### 1. Название
- [ ] Звучит по-мужски? (не "Нирвана", а "Смирение")
- [ ] Соответствует КЭМП? (дисциплина, братство, бой, выносливость)
- [ ] Не слишком длинное (1–3 слова)

### 2. Описание
- [ ] Понятно с первого прочтения?
- [ ] Не слишком "эзотерично"? (мы не йога-приложение)
- [ ] Длина: 1–3 предложения. Не эссе.

### 3. Задание
- [ ] Реально выполнить за 1 день?
- [ ] Не опасно для здоровья?
- [ ] Можно проверить "сделал / не сделал"?

## Примеры правок (как это делается)

### Пример 1: мелкая правка
```
Было:  id: 7, name: "ДЫХАНИЕ"
Стало: id: 7, name: "ДЫХАНИЕ ВОИНА"
```

### Пример 2: переделать описание
```
Было:  "Владение дыханием = владение собой..."
Стало: "Боец контролирует дыхание в ударе. Ты — нет. Тренируй."
```

### Пример 3: заменить задание
```
Было:  "10 минут дыхательной практики Вим Хофа..."
Стало: "3 раунда квадратного дыхания: вдох 4с, пауза 4с, выдох 4с, пауза 4с"
```

### Пример 4: клетка не нравится — полная переделка
```
Было:  id: 33, name: "ПАМЯТЬ"
Стало: id: 33, name: "ОПЫТ" (новое название + новое описание + новое задание)
```

## Формат правки (просто пиши в чат)

Не обязательно лезть в код. Можешь писать прямо мне:

```
Клетка 17 (ДИСЦИПЛИНА):
- Название: оставить
- Описание: сократить, убрать "Мотивация умирает..."
- Задание: заменить на "7 дней без нарушения режима сна"

Клетка 44 (ГОРДЫНЯ):
- Полностью переделать. Предлагаю: "Корона давит. Сними."
```

Я сам внесу в `cells-draft.md` и `lib/cells.ts`.
